# Unicorns vs Dinosaurs

Dash. Leap. Roar. Race together!

Public downloads for Windows PC and Linux / Steam Deck. This repository contains release packages and installation information. Game source is maintained separately and is not published here.

## Download

**[Get the latest release](https://github.com/JENkt4k/unicorns-vs-dinosaurs-releases/releases/latest)**

- Steam Deck / Linux: choose `unicorns-vs-dinosaurs-linux-vX.Y.Z.zip`.
- Windows: choose `unicorns-vs-dinosaurs-windows-vX.Y.Z.zip`.

Extract the ZIP before launching. Keep the executable and `unicorns-vs-dinosaurs.pck` together in a writable folder. No GitHub account is required to download a public release.

## Steam Deck

1. Switch to Desktop Mode and extract the Linux ZIP to a permanent folder, such as `/home/deck/Games/unicorns-vs-dinosaurs/`.
2. Allow `unicorns-vs-dinosaurs.x86_64` to run as a program in file Properties if necessary.
3. Add that executable to Steam as a non-Steam game; set **Start In** to its folder. The native Linux build does not require Proton.
4. Return to Gaming Mode. Optional Steam artwork is included in the ZIP's `steam-artwork` folder.

## Updating

The currently mirrored v0.2.8 build predates the in-game updater. Install the first updater-enabled release manually once. In supported later builds, use **Options > About > Game Updates** to check, download, and **Install & Quit**, then restart from Steam or your shortcut. Keep the same folder so the Steam shortcut continues to work. Saves and settings are stored separately from the executable and pack.

`SHA256SUMS.txt` accompanies mirrored releases. The updater additionally verifies downloads against GitHub's SHA-256 asset digest.
